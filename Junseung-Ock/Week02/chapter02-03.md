### 결론
- 메모리는 빠르지만 디스크는 아직 느리다
- 디스크 탐색은 가능한 한 피한다
- 단순한 압축 알고리즘은 빠르다
- 데이터를 인터넷으로 전송하기 전 가능하면 압축한다
- 데이터 센터는 여러 지역에 분산되어 있고, 센터들 간에 데이터를 주고받는 데는 시간이 걸린다

# Chapter 03
## 시스템 설계 면접 공략법
### 효과적인 면버을 위한 4단계 접근법
- 1단계 문제 이해 및 설계 범위 확정
  - 요구사항과 가정들을 분명히 하기
    - 구체적으로 어떤 기능을 만들어야 하는가?
    - 제품 사용자 수는 얼마 되는가?
    - 회사 규모 성장 속도는?
    - 회사가 주로 사용하는 기술 스택은?
    - 설계를 단순화하기 위해 활용할 수 있는 기존 서비스는?
- 2단계 개략적인 설계안 제시 및 동의 구하기
  - 면접관과 협력하며 진행
    - 설계안에 대한 최초 설계도를 제시하고 의견 구하기
    - 핵심 컴포넌트를 포함하는 다이어그램 그리기
    - 최초 설계안이 시스템 규모에 관계된 제약사항을 만족하는지 개략적으로 계산
- 3단계 상세 설계
  - 달성한 목표
    - 시스템에서 전반적으로 달성해야 할 목표와 기능 범위 확인
    - 전체 설계의 개략적 청사진 마련
    - 해당 청사진에 대한 면접관의 의견 청취
    - 상세 설계에서 집중해야 할 영역들 확인
  - 특정 부분에 대한 상세한 설명 요구
    - 불필요한 세부사항에 시간 투자 x
- 4단계 마무리
  - 후속 질문 or 스스로 추가 논의
    - 개선 가능한 지점 찾기 -> 없다고 하지 않기
    - 설계 전체적 요약
    - 오류 발생 시 일어나는 일
    - 운영 이슈
    - 규모 확장 요구에 대한 대처
## 정리
### 면접 세션에서 해야 할 것
- 질문을 통해 확인
- 문제의 요구사항 이해
- 정답이나 최선의 답안은 없다
- 사고 흐름을 이해할 수 있도록 소통
- 가능한 여러 해법 제시
- 개략적 설계에 면접관 동의 시 컴포넌트 세부사항 설명 시작 (가장 중요한 컴포넌트부터)
- 면접관 아이디어 끌어내기
### 하지 말아야 할 것
- 대비 없이 면접
- 요구사항 및 가정이 분명하지 않은 상태에서 설계 제시
- 처음부터 특정 컴포넌트에 대해 너무 깊게 설명
- 막히면 힌트 청하기
- 소통하기
### 시간 배분
- 1단계 3-10분
- 2단계 10-15분
- 3단계 10-25분
- 4단계 3-5분
